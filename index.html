📊 Excel Import Guide for Leads

📋 Required Excel Format

Your Excel file should have the following column headers in the first row. Column names must match exactly (case-sensitive):

# Column Name (Required) Description
1 Contact Person Full name of contact person
2 Phone Number Primary contact number
3 Company Name Company or project name
4 Project Address Complete project address
5 City City name
6 Elevator Type Passenger, Goods, Hospital, Car, Home, etc.
7 Quantity Required Number of elevators (numeric value)
8 Lead Source Website, Referral, Cold Call, Exhibition, Social Media, etc.
9 Lead Priority Hot, Warm, or Cold
10 Assign To Sales rep username

💡 Important Notes:

  • Column headers must match exactly as shown above (including spaces and capitalization)
  • All 10 fields are required - each row must have values in all columns
  • Empty rows will be skipped automatically
  • The file can be in .xlsx, .xls, or .csv format
  • Maximum 1000 leads can be imported at once
  • Invalid data will be skipped with a detailed error report

📝 Example Excel Format:

Contact Person Phone Number Company Name Project Address City Elevator Type Quantity Required Lead Source Lead Priority Assign To
John Doe 9876543210 ABC Corp 123 Main St, Andheri Mumbai Passenger 2 Website Hot admin
